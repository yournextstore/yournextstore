# Notice

This theme ports the visual design of **HULL** by Nick DiMatteo
(https://github.com/ndimatteo/HULL, demo https://hull.dev) onto the Your Next Store storefront:
the paper-and-ink palette with its dark mode, the 1px ink-ruled grid, pill buttons, the
centred-wordmark header with "○ SHOP / ○ INFO" mega navigation, the product marquee, the
dotted pagination and add-to-cart bands, the inverted cart and filter drawers and the
four-block footer with a theme switch.

The code was rewritten for this storefront; no HULL source files, images, logo or brand name are
shipped. The wordmark is the store name set in Six Caps (SIL Open Font License, via Google Fonts).
Photography comes from the store's own catalogue.
